# xj

`xj` is my simple tool for version-controllable work journals.
Originally I was using [`wj`](https://github.com/adamkpickering/wj)
but the time tracking made it difficult to jump between tasks
and maintain accuracy. `xj` is the same idea, but the file format
has been cut down to a "To Do" list, a "Worked On" list, and
unstructured notes.
